# Python Toolkit Lab

یک آزمایشگاه تعاملی برای ارائه‌ی کتابخانه‌ها و ابزارهای Python.

## هدف
به‌جای اجرای جداگانه‌ی هر تابع در محیط Python و جابه‌جایی بین File Explorer، Excel، ترمینال و برنامه‌های دیگر، ابزارها در یک رابط بصری نمایش داده می‌شوند.

ویژگی‌های نسخه‌ی اول:
- دسته‌بندی کتابخانه‌ها
- جستجوی کتابخانه، تابع و متد
- صفحه‌ی آزمایشگاه برای هر کتابخانه
- کارت تعاملی برای هر ابزار
- علامت `?` برای توضیح کاربرد، آرگومان‌ها و خروجی
- ساخت زنجیره‌ی کد با کلیک روی بلوک‌ها
- تولید نمونه‌ی Python
- Live Preview برای چندین ابزار
- حالت ارائه
- حالت روشن/تاریک
- بدون backend و مناسب GitHub Pages

## اجرا
فقط `index.html` را باز کنید.

## انتشار روی GitHub Pages
این پروژه static است و به سرور Python نیاز ندارد. GitHub Pages فایل‌های HTML/CSS/JS را از repository منتشر می‌کند.

1. سه فایل `index.html`, `styles.css`, `app.js` را در repository قرار دهید.
2. در GitHub به Settings → Pages بروید.
3. یک branch و folder برای انتشار انتخاب کنید.
4. آدرس GitHub Pages را باز کنید.

## نکته مهم
چون GitHub Pages فقط فایل‌های سمت مرورگر را اجرا می‌کند، توابع Python واقعاً روی سیستم بازدیدکننده اجرا نمی‌شوند. نسخه‌ی فعلی رفتار ابزارها را در قالب Preview شبیه‌سازی می‌کند و نمونه‌ی Python تولید می‌کند.

برای نسخه‌ی بعدی می‌توان یک Python Runner جداگانه طراحی کرد که کد واقعی را اجرا کند؛ آن نسخه نیاز به یک محیط اجرای Python خواهد داشت و بهتر است از سایت استاتیک جدا باشد.
